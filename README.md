# FTI Relations

### Connecting Through External Relations

FTI Relations merupakan sebuah website yang dikembangkan sebagai project FOSI (Fokus Satu Inovasi) Dinas Eksternal BEM KM Fakultas Teknologi Informasi Universitas Andalas.

Website ini bertujuan untuk menjadi media informasi dan dokumentasi hubungan eksternal antara BEM KM FTI UNAND dengan berbagai organisasi mahasiswa dari universitas lain.

Melalui platform ini, informasi mengenai organisasi mitra, profil organisasi, serta dokumentasi kegiatan hubungan eksternal dapat diakses dengan lebih mudah dan terstruktur.

## Tujuan Project

1. Memperkenalkan organisasi mahasiswa yang pernah menjalin hubungan eksternal dengan BEM KM FTI UNAND.
2. Menyediakan direktori organisasi sebagai pusat informasi hubungan eksternal.
3. Mendokumentasikan kegiatan BEM Visit dalam bentuk galeri foto.
4. Mempermudah akses informasi mengenai organisasi mitra.
5. Menjadi arsip digital kegiatan Dinas Eksternal BEM KM FTI UNAND.

## Fitur Utama

* **Organization Directory**
  Menampilkan daftar organisasi mahasiswa yang telah menjalin hubungan eksternal dengan BEM KM FTI UNAND.

* **Organization Details**
  Menyediakan informasi profil organisasi, kabinet, logo, dan tautan media sosial.

* **Activity Documentation**
  Menampilkan dokumentasi foto kegiatan BEM Visit sebagai arsip kegiatan hubungan eksternal.

* **Instagram Integration**
  Menghubungkan pengguna dengan akun Instagram masing-masing organisasi.

* **Back to Top**
  Memudahkan navigasi pengguna untuk kembali ke bagian atas halaman.

## Teknologi 

Project ini dikembangkan menggunakan teknologi berikut:

* **HTML5** – Membangun struktur halaman website.
* **CSS3** – Mengatur tampilan, layout, dan desain antarmuka.
* **JavaScript** – Mengimplementasikan interaksi dan fungsionalitas website.
* **Git & GitHub** – Mengelola source code dan version control.
* **GitHub Pages** – Menghosting website agar dapat diakses secara online.

## Deployment

Website ini menggunakan GitHub Pages sebagai layanan hosting.

Deployment dilakukan melalui repository GitHub sehingga website dapat diakses secara online tanpa memerlukan server hosting tambahan.
